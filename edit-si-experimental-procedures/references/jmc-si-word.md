# JMC Supporting Information in Word

## Choose the baseline

- Open the latest author-edited SI and the corresponding accepted manuscript. Use the SI template for layout and the manuscript or an author-confirmed crosswalk for compound identifiers. Apply the requested changes within the relevant sections and save a new dated version beside the source.
- For a new SI, use the manuscript title, author and affiliation details, an automatic Table of Contents, and the sections supported by the materials. A typical order is Chemistry, compound-grouped NMR and HRMS spectra, X-ray crystallographic data, Biology, HPLC Purity, and References. Preserve existing section labels and order when updating a supplied template. Keep deferred material in the slots the author provides.
- Use the template's effective styles. For a new Word file using this house style, use A4 portrait, 2.54 cm top and bottom margins, 3.175 cm left and right margins, and centered footer page numbers (S1, S2, …). Use Times New Roman for English and numerals, and 宋体 where Chinese text is needed. Use a centered bold 16 pt Supporting Information heading, a bold 14 pt manuscript title and section headings, and 12 pt body text. Default to justified prose with 1.25 line spacing, centered spectrum images, and left-aligned 12 pt captions. Use bold compound identifiers and true subscripts and superscripts in rich text.
- For characterization prose, apply [JMC characterization](jmc-characterization.md). Place appearance, isolated yield, and supported purity before NMR, followed by HRMS. Retain the author's stated values and leave missing evidence for confirmation. The standalone spectrum section holds figures and their captions.

## Assemble analytical figures

1. Build a working crosswalk for each compound with its current manuscript number, old sample identifier, spectrum file and page, experiment type, and HRMS report. Verify ambiguous identifiers against structures, experiment labels, and reported formula and m/z. Verify NMR and HRMS mappings independently when old labels disagree. Reuse an earlier export only when its source matches the current file. Preserve raw files and the processed spectrum's content.
2. Use the existing template crops as the visual reference. Crop blank margins and report headers where appropriate, keeping axes, peak labels, integrations, annotations, insets, and any relevant 2D projections readable. Use the original plotted data and retain supplied structure insets. Export current processed Mnova files when needed. Report unavailable or unconfirmed spectra separately.
3. Group figures by current manuscript compound number. Within each compound, use the default order ¹H, ¹³C, HSQC, COSY, HMBC, NOESY, then HRMS. Include the experiments supported by the sources. Follow any author-specified sequence for additional experiments. For 2D captions, include the verified proton frequency and solvent where the template uses them.
4. For each HRMS figure, choose one source spectrum displaying the target ion m/z, preferably the readable expanded trace. Place the source report table below it and the caption after both. Keep the three elements together under one Figure S number. Preserve the source table's formula, ion, calculated and measured m/z, and error values. Use an editable table when the source permits it and a clear crop for a PDF report. If a spectrum label and its report table differ, preserve each source value and record the discrepancy for review. Leave unresolved compound or ion matches unassigned.
5. Put each caption below its figure. A typical caption is **Figure S1.** ¹H NMR spectrum of **1**. Apply true Word superscripts to nucleus numbers. Use a shared Word sequence field, e.g. `SEQ FigureS \* ARABIC`, for the digits in all spectral captions, including existing ones in the edited section. Keep each figure or HRMS group with its caption, and aim for two readable figures per page. Allow a single figure where page space or figure size warrants it.

## Add crystallographic entries

- Match the source crystal identifier and the manuscript compound identifier. Use the final refinement CIF and the corresponding structure-refinement report or table. Consult supporting measurement metadata when a required experimental field is absent. Distinguish the final refinement record from coordinate-only exports and earlier refinements. Flag unresolved source conflicts and leave unavailable values for confirmation.
- Use the author template order: **X-ray Crystallographic Data for [compound]**, the existing or source crystal image, an **Experimental.** paragraph, and a **Crystal data for [compound]:** paragraph. Reuse accepted images. Follow the template's alignment and emphasis.
- For **Experimental.**, report the supported colour, crystal habit and dimensions, instrument, radiation and wavelength, collection temperature, and solution and refinement methods. Use the measurement conditions for that crystal.
- For **Crystal data**, report the crystallographic formula and molar mass, crystal system, space group and number, unit-cell lengths and angles, volume, temperature, Z, absorption coefficient, measured and independent reflections, and Rint. Distinguish observed-data and all-data R₁ and wR(F²), then give goodness of fit and the Flack parameter where reported. Preserve the CIF's precision and uncertainty notation. If the crystal formula includes solvent, identify the solvate and keep its crystal formula distinct from the parent compound's characterization formula. Include a deposition number when documented and requested or required by the template.
- Flow crystallographic entries consecutively. Keep each heading with its image where possible. Let experimental and refinement paragraphs continue naturally across pages without forcing a full crystal entry to stay together or start on a fresh page.

## Verify the Word result

- Check that compound labels agree with the manuscript and sources. Verify image crops, caption association, HRMS plot and table placement, crystal values and symbols, and the continuous Figure S sequence. Update the sequence and existing TOC page numbers after layout changes. In Word, fields can be refreshed with Ctrl+A, then F9.
- Preview the affected pages to check image readability, headings, and pagination. Compare sections outside the edit against the accepted source. Preserve unrelated text, figures, and styles and report any unresolved items separately from the SI.
